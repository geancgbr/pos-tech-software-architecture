# Ferramentas de Visualização do Neo4j

| Ferramenta | Público (segundo a aula 5) | O que é |
|---|---|---|
| **Neo4j Browser** | Desenvolvedores que dominam Cypher | Consultas **ad-hoc**, resultados em grafos e tabelas, **CRUD**, autocompletar; integrado ao Workspace |
| **Neo4j Bloom** | Analistas de dados que conhecem o modelo | Exploração **no-code**, "Pesquisa de Grafos" com palavras-chave, drilldowns, visões salvas e compartilhadas |
| **NeoDash** | Especialistas de domínio / usuários de negócios | **Dashboards low-code** com consultas Cypher, widgets interativos, tempo real, várias fontes de dados |

- **Na aula 1**: o **Bloom** é a ferramenta de **discovery** para **usuários de negócios** sem conhecimento técnico profundo, e o **Neodash** cria **dashboards** com métricas, gráficos e mapas ([[GR 01 - Fundamentos de grafos e a plataforma Neo4j]]). A aula 5 associa o Bloom aos **analistas** ([[GR 05 - Análise e visualização de dados com Neo4j]]).
