# Mapa de Contexto

A **materialização visual** dos [[Contexto Delimitado|contextos delimitados]] e de como eles se integram ([[Padrões de Integração entre Contextos|padrões]]). Dá a visão estratégica do todo.

É um **documento vivo**: atualize-o sempre, porque ele mostra se os subdomínios continuam fazendo sentido.
