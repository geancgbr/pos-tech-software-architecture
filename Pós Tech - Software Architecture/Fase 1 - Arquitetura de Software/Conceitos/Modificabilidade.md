# Modificabilidade

**Capacidade de o software ser modificado facilmente**: alterado, mantido e evoluído para atender novos requisitos e necessidades.

**Por que importa**: o software muda com frequência (corrigir defeitos, melhorar funcionalidades, novos requisitos, novos ambientes). Modificar com eficiência reduz tempo e custo, melhora a qualidade e mantém o sistema atendendo o usuário.

| Fator | Como afeta |
|---|---|
| Design de software | Design modular e bem estruturado, com componentes bem definidos e interações documentadas |
| Arquitetura de software | Facilita adicionar e remover componentes e evoluir o sistema |
| Qualidade do código | Legibilidade, padrões de codificação, pouco código duplicado, nomes significativos |
| Documentação | Completa e atualizada: design, código e processo |
| [[Testabilidade]] | Testes automatizados garantem que as alterações não causem regressão ou defeitos |

Também deve ser considerada um **requisito importante** do software.
