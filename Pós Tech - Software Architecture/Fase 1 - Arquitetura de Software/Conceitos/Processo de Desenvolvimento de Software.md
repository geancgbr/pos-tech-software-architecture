# Processo de Desenvolvimento de Software

Abordagem **sistemática e disciplinada** que visa garantir **qualidade, eficiência e eficácia** do software.

**Etapas**: análise de requisitos → design → implementação → testes → manutenção. Cada uma é importante para que o software atenda aos requisitos e funcione corretamente.

- Para quem trabalha com DDD, o levantamento de requisitos corresponde à **[[Modelagem Tática]]**: entrevistar clientes e stakeholders.
- O analista deve ter em mente as **regras de negócio** (tudo o que o sistema precisa ter para existir), porque elas são cruciais para a arquitetura.
- Registre a **[[Linguagem Ubíqua]]**: muitos analistas esquecem, e ela ajuda a voltar a conversar com os stakeholders.
