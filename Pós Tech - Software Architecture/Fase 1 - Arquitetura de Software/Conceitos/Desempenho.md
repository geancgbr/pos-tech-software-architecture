# Desempenho

**Medida de quão bem um sistema executa uma tarefa** em relação às expectativas ou aos requisitos, ou seja, a capacidade de cumprir suas funções de forma eficiente e eficaz.

| Dimensão | Definição |
|---|---|
| Tempo de resposta | Quanto tempo leva para responder a uma solicitação do usuário |
| Taxa de transferência | Quantidade de dados transferidos num período |
| Utilização de recursos | Processamento, memória e armazenamento usados numa tarefa |
| Confiabilidade | Funcionar sem falhas ou interrupções por longos períodos |
| [[Escalabilidade]] | Lidar com mais usuários, dados ou solicitações sem perder desempenho |

É uma preocupação crítica em serviços de internet, jogos, computação de alto desempenho e outros setores. Uma das formas de melhorá-lo é a [[Estratégias de Cache|estratégia de cache]].
