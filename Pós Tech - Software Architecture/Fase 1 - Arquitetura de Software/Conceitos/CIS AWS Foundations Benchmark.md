# CIS AWS Foundations Benchmark

Framework do **Center for Internet Security (CIS)** com configurações seguras e boas práticas para fortalecer a segurança na **nuvem AWS**.

- Versão **1.4.0**, a última lançada, com **2 níveis de conformidade**.
- É uma ferramenta **dinâmica**, atualizada regularmente para novas ameaças.
- É um dos padrões do **AWS Security Hub**.

**10 pontos**: identidade e acesso gerenciado · monitoramento e registro · armazenamento seguro (S3) · rede segura (firewall NAT, regras de segurança de grupo, VPC) · segurança de máquinas virtuais (EC2) · gerenciamento de configuração (AWS Config) · segurança da informação · conformidade e integridade · segurança em nível de aplicação (Lambda, bancos) · planejamento e gestão de emergências.

A descrição de cada ponto está em [[DS 06 - Padrões de segurança#CIS AWS Foundations Benchmark]].
