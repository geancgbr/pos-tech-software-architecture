# Clean Architecture (livro)

Livro de **Robert C. Martin ("Uncle Bob")**. É um guia para criar sistemas de alta qualidade, com práticas e princípios para desenvolver de forma mais eficiente e sustentável.

| Ponto principal | Ideia |
|---|---|
| **Separação de preocupações** | Cada parte do sistema tem um propósito específico e não assume mais do que o necessário |
| **Responsabilidade única** | Cada módulo, classe ou função tem uma única responsabilidade |
| **Abstração** | As partes são independentes das implementações específicas, o que facilita alterar ou ampliar o sistema |
| **Depuração fácil** | O sistema facilita depurar problemas quando eles surgem |
| **Simplicidade** | O mais simples possível, sem componentes desnecessários ou redundâncias |

Na aula 5, a apostila diz que os objetivos da [[Arquitetura Hexagonal]] são parecidos com os da arquitetura limpa.
