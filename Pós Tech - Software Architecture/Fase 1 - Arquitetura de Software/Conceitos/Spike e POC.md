# Spike e POC

Formas de **validar uma solução técnica antes do desenvolvimento**, reduzindo o risco técnico e melhorando as estimativas.

| | Spike | POC |
|---|---|---|
| O que é | Item de desenvolvimento para **explorar e aprender** | **Prova de conceito**: a ideia atende ao objetivo? |
| Onde entra | **Dentro da sprint** | **Antes de ir para "produção"** |
| Quando usar | Fluxos ou validações complexas | Validar uma solução técnica específica |
