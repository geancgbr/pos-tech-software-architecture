# OWASP Juice Shop e WebGoat

Dois projetos do [[OWASP]] para **treinar segurança de aplicações web** num ambiente controlado.

- **Juice Shop**: aplicação **deliberadamente insegura**, com falhas das mais básicas às mais complexas. Benefícios: aprendizado prático sem arriscar sistemas reais, sensibilização e aprimoramento de habilidades.
- **WebGoat**: projeto **open-source** de treinamento. "Web" + "Goat" (**bode**): um alvo para praticar.

| | WebGoat | Juice Shop |
|---|---|---|
| Enfoque | **Lições**, cada uma com um desafio sobre uma vulnerabilidade (SQL Injection, XSS, autenticação, controle de acesso) | **E-commerce inseguro** com desafios contínuos |
| Ambiente | Uma vulnerabilidade por vez, com instruções | Experiência contínua e dinâmica |
| Realismo | Plataforma de treinamento, conceitos isolados | Simula um e-commerce real |
| Tecnologias | **Várias** (Java, .NET, Node.js...) | **Só JavaScript/Node.js** |

A apostila sugere usar **os dois**.
