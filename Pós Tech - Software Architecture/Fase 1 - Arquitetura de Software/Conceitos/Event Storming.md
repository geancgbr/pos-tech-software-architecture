# Event Storming

Workshop **lúdico e colaborativo** com post-its coloridos para modelar o processo de negócio. Vai dos [[Evento de Domínio|eventos]] até os [[Agregado|agregados]] e [[Contexto Delimitado|contextos delimitados]].

**Ordem**: brainstorming → linha do tempo → pontos de atenção → eventos pivotais → comandos e atores → políticas → modelos de leitura → sistemas externos → agregados → contextos.

**Cores**: evento 🟧 · ponto de atenção 🩷 (losango) · comando 🟦 · ator 🟨 · política 🟪 · modelo de leitura 🟩 · sistema externo 🩷 · pivotal ┃

**Equipe**: Domain Experts, ouvintes e facilitador. Material: parede ou Miro/FigJam.
