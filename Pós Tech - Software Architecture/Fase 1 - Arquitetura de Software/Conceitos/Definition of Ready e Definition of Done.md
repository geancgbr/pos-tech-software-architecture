# Definition of Ready e Definition of Done

- **DoR**: o portão de **entrada**. Condições para a tarefa **começar**: descrição clara, critérios de aceitação, dependências identificadas.
- **DoD**: o portão de **saída**. Critérios para a tarefa ser **concluída**: qualidade de código, testes unitários e de aceitação, code review, documentação, aprovação do PO.

Exemplo do curso:
- **DoR**: requisitos documentados, refinamento técnico feito, arquitetura desenhada, quebra em itens, estimativa, priorização pelo PM ou PO.
- **DoD**: code review, aprovação da QA, validação com o usuário final.
