# OWASP

Organização que **promove práticas de segurança de software** e melhora a segurança de aplicações web no mundo. Desenvolve e compartilha projetos com a comunidade, além de manter capítulos, treinamentos e Meetups.

| Projeto                                          | O que é                                                                                                                                                                                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **OWASP Top 10**                                 | O **principal projeto**. Ter código preparado para essas vulnerabilidades é considerado **boa prática no mercado**. Os vídeos tratam das mudanças entre 2017 e 2021 e das 4 vulnerabilidades mais comuns (a lista não está no texto do PDF) |
| [[OWASP Dependency-Track]]                       | Gestão de dependências e dos seus riscos                                                                                                                                                                                                    |
| [[OWASP Juice Shop e WebGoat\|OWASP Juice Shop]] | Aplicação web deliberadamente insegura (e-commerce) para treinamento                                                                                                                                                                        |
| [[OWASP Juice Shop e WebGoat\|OWASP WebGoat]]    | Plataforma de treinamento open-source baseada em lições                                                                                                                                                                                     |
| [[OWASP Web Security Testing Guide]]             | Guia de testes de segurança em aplicações web                                                                                                                                                                                               |

No Hands On, a aula usa a **ferramenta OWASP ZAP** para encontrar vulnerabilidades no código.
