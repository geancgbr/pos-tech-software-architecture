# Testabilidade

**Capacidade de o software ser testado de maneira eficaz**, ou seja, avaliado com facilidade quanto a qualidade, funcionalidade e desempenho. Inclui a facilidade de **criar, executar e manter** testes.

**Por que importa**: sem testes adequados, é difícil garantir os requisitos. Quanto mais testável, menos tempo e recursos para testar, o que reduz custo e prazo.

| Fator | Como afeta |
|---|---|
| Design de software | Código modular, legível e reutilizável facilita criar testes |
| Arquitetura de software | Uma arquitetura bem projetada reduz a complexidade |
| Instrumentação de código | Código adicional que coleta dados para análise, monitoramento e teste |
| Dados de teste | Dados relevantes e realistas são essenciais |
| Ferramentas de teste | Automação aumenta eficiência e eficácia |
| Acessibilidade de interfaces | Interfaces bem definidas e documentadas facilitam os testes |

A testabilidade deve ser um **requisito importante**, e não um processo secundário ou opcional. Ela também é um dos fatores da [[Modificabilidade]].
