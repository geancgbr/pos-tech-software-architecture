# OWASP Web Security Testing Guide

Guia **abrangente e prático para testes de segurança em aplicações web**, dos conceitos fundamentais às técnicas avançadas. Ajuda a identificar e mitigar vulnerabilidades. É **revisado periodicamente** pela comunidade [[OWASP]].

**Seções citadas**: Information Gathering · Configuration and Deployment Management Testing · Identity Management Testing · Authentication Testing (força bruta, senha, MFA) · Session Management Testing · **Input Validation Testing** (SQL Injection, XSS) · Error Handling Testing.

A descrição de cada seção está em [[DS 05 - OWASP e OWASP Top 10#OWASP Web Security Testing Guide]].
