# Manutenibilidade

Na disciplina Desenvolvimento Seguro (aula 4): a **capacidade de o código-fonte ser facilmente compreendido, modificado, corrigido e estendido** ao longo do tempo. É crítica para o software continuar útil e eficaz depois da implementação inicial.

A manutenção é **inevitável** (os requisitos evoluem, entram recursos, aparecem bugs). O código deve permitir mudanças com o **mínimo de esforço e risco**.

**Práticas**: clareza e legibilidade · [[Modularização|modularização]] · [[Teste de Unidade|testes unitários]] · gerenciamento de dependências · padrões de codificação · refatoração · documentação adequada.

Investir nisso **desde o início** economiza tempo e recursos. É o gancho da aula para a [[Análise Estática de Código]].
