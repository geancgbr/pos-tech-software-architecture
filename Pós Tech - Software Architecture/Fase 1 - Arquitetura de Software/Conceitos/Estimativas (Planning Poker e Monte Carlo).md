# Estimativas (Planning Poker e Monte Carlo)

- **Planning Poker (Fibonacci: 1, 2, 3, 5, 8...)**: pontua tamanho e complexidade. O maior valor está em **provocar a discussão** dos impactos no time. **Sem base histórica, é pouco assertivo.**
- **Monte Carlo**: complementar. Usa o histórico para dar a **probabilidade** de o time entregar N itens no período. Exemplo da aula: o time entrega 27 itens ou mais em 79,7% das sprints.
