# Pós Tech - Software Architecture

Notas pessoais de estudo da pós-graduação **FIAP Pós Tech - Software Architecture**, escritas em Markdown para o [Obsidian](https://obsidian.md).

> As notas resumem as apostilas do curso para estudo pessoal. Os PDFs e o material original da FIAP não fazem parte deste repositório.

## Como usar
Abra esta pasta como vault no Obsidian. Os links `[[...]]`, o grafo e as perguntas dobráveis das revisões só funcionam lá; no site do GitHub, as notas aparecem como Markdown simples.

## Estrutura
- `Pós Tech - Software Architecture.md`: índice geral, com o status de cada fase.
- Uma pasta por fase (`Fase 1` a `Fase 5`), cada uma com:
  - a nota índice da fase e `Revisão - <fase>.md`;
  - `Conceitos/`: uma nota por conceito, ligada às aulas em que aparece;
  - uma pasta por disciplina, com o índice, `Aulas/` (notas prefixadas, como `DDD 01 - ...`) e `Revisão - <disciplina>.md` com perguntas e respostas.
